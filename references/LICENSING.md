# Reference Library Licensing and Storage Policy

## Purpose

The local reference library supports research, implementation verification,
technical note writing, and theory-to-code traceability for the AeroFlex
benchmark.

## Git Policy

The following are tracked:

- bibliographic metadata;
- DOI and publication metadata;
- canonical IDs;
- reference notes;
- theory-to-code mappings;
- section and page indexes;
- relationships between complete works, extracts, and duplicate filenames;
- licensing and provenance notes.

The following are excluded by default:

- publisher PDFs;
- downloaded thesis PDFs;
- local article copies;
- temporary OCR or text-extraction products.

## PDF Location

Local PDF copies are stored under:

```text
references/pdf/
```

Redistribution permission must be verified separately for each document.
Local possession does not authorize inclusion in a software release.
